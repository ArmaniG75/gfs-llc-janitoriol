# GFS LLC of San Antonio Janitorial Services

Website files for GFS LLC of San Antonio Janitorial Services.

## Important: Formspree

The contact form is prepared for Formspree, but the Formspree form ID still needs to be connected.

In `index.html`, find:

`https://formspree.io/f/REPLACE_WITH_YOUR_FORMSPREE_ID`

and replace the placeholder with the Formspree endpoint you receive after creating your form.

The business street address is intentionally not included on the public website.
